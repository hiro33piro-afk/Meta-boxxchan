Welcome to MiniOS!

MiniOS is a tiny 16-bit operating system written in x86 assembly.
It runs on a real (emulated) PC inside your web browser.

Try these commands:
  cpu        show the emulated CPU
  mem        show installed memory
  calc 6 * 7 use the calculator
  gfx        VGA graphics demo
  write notes.txt Hello!   create a file
  ls         list files

Files are stored on the virtual floppy disk.
